Como entrar

Escolha seu sistema. O modo automático (cole o comando) baixa o jogo (Zandronum 3.2.1 + Freedoom) na primeira vez e já entra no servidor. Das próximas vezes só abre o jogo.

Automático (recomendado)

  1. Aperte a tecla Windows, digite PowerShell e abra (não precisa ser administrador).
  2. Cole e aperte Enter:

O jogo fica em C:\Users\<seu usuário>\Doom. Script: ⬇ baixar win.ps1 (leia antes de rodar, se quiser).

Quer outra pasta? Baixe o win.ps1, abra no Bloco de Notas, edite a linha $Dir = … e rode no PowerShell: powershell -ExecutionPolicy Bypass -File "$HOME\Downloads\win.ps1"

Manual

  1. Baixe o Zandronum 3.2.1: instalador ou zip (se for o zip, extraia numa pasta). Página oficial: zandronum.com/download.
  2. Baixe o Freedoom 0.13.0, extraia e copie o freedoom2.wad para a pasta do Zandronum (onde está o zandronum.exe).
  3. Abra o Zandronum (escolha freedoom2.wad se perguntar), aperte ' ou ~ e digite: connect …

Antes: bibliotecas do seu Linux

O Zandronum para Linux (o do script) precisa de libSDL-1.2 e libjpeg.so.8. Instale conforme sua distro:

DistroComando
Ubuntu / Linux Mintsudo apt install libsdl1.2debian libjpeg-turbo8
Debian 13 (e derivados sem libjpeg.so.8)Não existe a libjpeg.so.8. Use o repositório apt oficial do Zandronum (abaixo) em vez do script.
Arch / Manjaropacote zandronum (AUR)

Debian / Ubuntu / Mint: pelo repositório oficial (sem libjpeg)

sudo wget -O /usr/share/keyrings/drdteam.gpg https://debian.drdteam.org/drdteam.gpg echo "deb [signed-by=/usr/share/keyrings/drdteam.gpg] https://debian.drdteam.org/ stable multiverse" | sudo tee /etc/apt/sources.list.d/drdteam.list sudo apt update && sudo apt install zandronum mkdir -p ~/.zandronum && wget -qO /tmp/fd.zip https://github.com/freedoom/freedoom/releases/download/v0.13.0/freedoom-0.13.0.zip && unzip -oj -q /tmp/fd.zip '*/freedoom2.wad' -d ~/.zandronum zandronum -iwad ~/.zandronum/freedoom2.wad +connect …

Repositório não oficial da DRD Team, listado em zandronum.com/download. Nesse modo você não usa o script abaixo.

Automático (recomendado)

Abra o Terminal, cole e aperte Enter:

O jogo fica em ~/Jogos/doom. Script: ⬇ baixar linux.sh.

Quer outra pasta? Baixe o linux.sh, edite a linha DIR=… e rode: bash ~/Downloads/linux.sh (ou sem editar: DOOM_DIR=/outra/pasta bash linux.sh)

Manual

  1. Baixe o Zandronum 3.2.1 para Linux e extraia numa pasta: mkdir -p ~/Jogos/doom && tar -xjf zandronum3.2.1-linux-x86_64.tar.bz2 -C ~/Jogos/doom
  2. Baixe o Freedoom 0.13.0, extraia e copie o freedoom2.wad para a mesma pasta.
  3. Rode: cd ~/Jogos/doom && LD_LIBRARY_PATH=. ./zandronum -iwad freedoom2.wad +connect …

Quer jogar os mapas de deathmatch (UDMX, AeonDM...)? Baixe os WADs aqui.

Use a versão 3.2.1 do Zandronum (as "testing 3.3" não entram neste servidor). Opcional: Doomseeker (lista de servidores).
